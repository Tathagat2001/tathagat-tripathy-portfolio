# Tathagat Tripathy — Portfolio V2

Interactive Power BI-style portfolio built with vanilla HTML, CSS and JavaScript.

## V2 features
- Executive analytics dashboard layout
- Interactive KPI cards
- Interactive SVG performance chart with four metric views
- Capability radar visualization
- Impact analytics cards
- Project Explorer with Python / Security / AI filters
- Click-to-expand project details
- Technology stack dashboard
- Career timeline
- Certification cards
- Responsive mobile experience
- No framework or build process required

## Run
Open `index.html`, or run `python -m http.server 8000`.

## Deploy
Suitable for GitHub Pages, Netlify, Vercel, Cloudflare Pages or any static host.

## Content
The portfolio content is based on the supplied resume. Metrics and project claims are not invented beyond that source.
